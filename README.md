# Free5GC + IMS 部署指南

## 环境准备

下载镜像包，使用 https://github.com/acore2026/free5gc-compose/tree/ran00101，ran00101分支，为根目录

需要安装：
- VM (虚拟机)
- Docker
- Docker Compose

## 使用场景

### 场景一：空白电脑，从零搭建

```bash
cd 5GC
./start-all.sh
```
一键启动核心网和话音网元

### 场景二：清空当前核心网所有用户和上下文，并重启

```bash
./clean_ue_context.sh
```
一键清除所有用户db数据和上下文（不包括签约数据）

### 场景三：重启核心网和IMS（含清理UE上下文、重新加载gtp5g模块）

```bash
./restart-all.sh
```

脚本执行流程：
1. 停止 IMS 服务（kamailio / free5gc-disable-offload / free5gc-ue-routes）
2. 停止 Docker 容器
3. 重新加载 gtp5g 内核模块
4. 启动 Docker 容器，等待 MongoDB 就绪
5. 清理 UE 上下文（AMF接入上下文 + 认证状态）
6. 配置网络（eth1 IP / br-free5gc IP）
7. 启动 IMS 服务

### 场景四：IMS网元或网络不通

```bash
cd 5GC
./init_env.sh
./stop-ims.sh
./start-ims.sh
```

### N接口说明

| 接口 | 协议 | 端点 | 说明 |
|------|------|------|------|
| N1 | NAS | UE ↔ AMF | UE与核心网信令 |
| N2 | NGAP/SCTP | gNB(.212/.125) ↔ AMF(10.88.120.100):38412 | 接入网信令 |
| N3 | GTP-U/UDP | gNB(.212/.125) ↔ UPF:2152 | 用户面数据 |
| N4 | PFCP/UDP | SMF ↔ UPF:8805 | 会话管理 |
| Nnrf | HTTP | 各NF ↔ NRF:8000 | 服务发现 |

- **PLMN**: MCC=001, MNC=01
- **切片1**: SST=1, SD=000000 (默认切片)
- **切片2**: SST=1, SD=112233
